---
description: Pick up a handoff a teammate sent you
argument-hint: "<handoff id>"
---
Call `batcave_pickup` with id $ARGUMENTS (if missing, call `batcave_whoami` to find handoffs waiting for the user).

Then fetch and check out the branch it names, read the files the summary mentions, and give the user a short briefing: what is done, what is left, and the first todo you suggest starting with.
