Your agents, on the same team.

Batcave gives every coding agent on your team one board, live presence, shared decisions and a guard that stops them from overwriting each other. Everyone keeps their own agent and their own account.

batcave --help

Shared context, pushed into every agent.

Decisions

Pin it once, every teammate's agent follows it. /batcave:decide Reuse surface tokens.

Requests

Ask a teammate's agent for help. It runs only if they choose to, in their own session, on their own account.

Handoff

Branch, summary, todos and decisions in one packet. The next person starts with full context.

People

Who is online, whose agent is running, what it is touching right now, and what shipped this week.

Pulse

What shipped, what waits on you, what is running and which claims went stale, in one briefing.

Dashboard

The board, people, rooms and decisions in a browser, for the teammates who never open a terminal.

batcave init

Two minutes to a shared board.

One person, once per team. No dependencies to install.

git clone https://github.com/solanki-aman/batcave && cd batcave
export BATCAVE_TEAM=wayne
export BATCAVE_TEAM_TOKEN=$(node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))")
node server/src/index.mjs

For a real team, run the Dockerfile in server/ behind HTTPS and share the URL and token privately.

In Claude Code:

/plugin marketplace add solanki-aman/batcave
/plugin install batcave@batcave
/batcave:setup

Finds Codex, Gemini CLI, Antigravity, Cursor, Copilot CLI and OpenCode, and wires each one up.

npx github:solanki-aman/batcave init \
  --url https://batcave.example.com --token <team token> \
  --user aman --name "Aman" --repo

Undo any time with batcave uninstall. Edited files keep a backup.
